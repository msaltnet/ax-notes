# AX Notes App

> 읽고, 직접 해보고, 만드는 과정을 함께 따라가는 AX 채널.

AX Notes App은 [AX Notes](https://github.com/dev-team-404/ax-notes)의 글을 읽는 독자를 위한 앱입니다. AI Transformation을 실제 생활과 업무에서 어떻게 활용하는지 소개하고, 글에서 얻은 아이디어를 Labs에서 실험하고 Project의 진행 과정을 따라갈 수 있는 경험을 만듭니다.

독자에게 쓸모 있는 AX 경험을 전달하면서, AX Notes를 만드는 개인의 관점과 작업을 알리는 브랜딩 채널로 운영합니다. 장기적으로는 광고를 붙여 지속 가능한 수익도 실험합니다.

## 프로젝트 목표

- 글 읽기에서 작은 실험과 프로젝트 참여로 이어지는 경험을 만든다.
- 독자가 작성자의 생각, 선택, 시행착오와 결과물을 통해 작성자를 알아가도록 한다.
- 앱을 만드는 과정 자체를 AX Notes의 Project로 기록한다.
- 직접 사용하고 독자의 반응을 확인하면서 개선하고, 이후 광고 수익화를 검토한다.

## 독자의 경험

**Note → 직접 해보기 → Lab → 관련 Project 따라가기**를 핵심 흐름으로 삼습니다. Project에서 새 진행 상황을 발견하고 관련 Note로 돌아오는 흐름도 제공합니다.

| 콘텐츠 | 앱에서의 역할 |
| --- | --- |
| Notes | AX 경험과 생각을 읽고 관련 실험을 발견하는 출발점 |
| Labs | 도구를 직접 실행하고 결과를 복사하거나 내려받는 참여 공간 |
| Projects | 목표, 진행 상태, 기록, 결과물을 함께 살펴보는 채널 |
| 작성자 소개 | 콘텐츠와 프로젝트를 만든 사람의 관점과 활동을 알아가는 연결점 |

## 첫 버전에서 검토할 범위

아래는 설계를 위한 후보이며, 구현이 확정된 기능은 아닙니다.

- Notes 목록과 글 읽기, 관련 Lab·Project 연결
- Labs 소개와 실행 진입점
- Project별 목표, 상태, 최신 기록과 결과물
- 작성자 소개와 외부 활동 채널 연결
- 참여 기능 하나를 작게 만들어 실제로 사용해보기

재미있는 참여 기능 후보는 **오늘의 AX 실험**입니다. 글 하나와 짧은 실습 하나를 묶어 제공하고, 독자가 결과물을 가져가거나 자신의 일에 적용해보도록 합니다. 북마크, 프로젝트 팔로우, 업데이트 알림, 실험 완료 기록 등은 첫 참여 경험을 검증한 뒤 우선순위를 정합니다.

## 개인 브랜딩과 수익화

브랜딩의 중심은 작성자의 실제 경험과 관점입니다. 글, 도구, 프로젝트에서 어떤 문제를 만났고 왜 이런 선택을 했는지 일관되게 보여줍니다. 작성자 소개와 관련 활동으로 자연스럽게 이어지는 연결을 마련합니다.

수익화는 독자가 반복해서 사용하는 경험을 먼저 확인한 뒤 광고로 시작하는 방향을 검토합니다. 광고 위치, 형식, 제공업체는 아직 정하지 않았습니다. 광고와 편집 콘텐츠는 명확히 구분하고, 읽기와 실험을 방해하지 않는 구성을 지향합니다.

## 만드는 과정을 글로 남기기

앱 개발은 AX Notes의 독립적인 **Project**로 다룹니다. 이 저장소에는 앱 코드와 설계 자료를 두고, 독자에게 공개할 글은 AX Notes Public의 Note로 작성해 해당 Project에 연결합니다.

예상 기록 흐름:

1. 왜 AX Notes에 앱이 필요한가 — 독자의 경험, 개인 브랜딩, 기대하는 변화
2. 무엇부터 만들 것인가 — 참여 흐름과 첫 버전의 범위
3. 어떤 방식으로 만들 것인가 — 플랫폼과 기술 선택의 이유
4. AI와 함께 만들기 — 실제 작업, 시행착오, 수정한 결정
5. 직접 써보고 고치기 — 사용 경험과 독자의 반응
6. 배포와 수익화 실험 — 운영 결과와 다음 과제

각 글에는 실제로 진행한 일, 선택의 이유, 확인한 결과, 남은 질문을 기록합니다. 구현하지 않은 기능이나 검증하지 않은 성과를 완료한 것처럼 소개하지 않습니다.

## 현재 상태

- 첫 독자 참여 기능과 성공을 확인할 기준
- 기존 AX Notes Public 콘텐츠를 가져오는 방식
- Labs 실행 방식과 Project 업데이트 전달 방식
- 저장 데이터, 계정 필요 여부와 알림 범위

## 저장소 구성

이 저장소의 원격 주소는 `git@github.com:msaltnet/ax-notes.git`입니다. AX Notes 상위 저장소에서는 `app/` 서브모듈로 관리합니다. 기존 Public과 Inside는 각자의 콘텐츠와 빌드를 운영하고, 앱은 별도 코드와 배포 단위를 가집니다.

```bash
# 상위 저장소에서 앱 받기
git submodule update --init --recursive app

# 앱 저장소만 받기
git clone git@github.com:msaltnet/ax-notes.git
```

개발 실행과 빌드 방법은 기술 선택 후 추가합니다.
