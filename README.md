# AX Notes App

> 읽고, 직접 해보고, 만드는 과정을 함께 따라가는 AX 채널.

AX Notes App은 AI Transformation을 실제로 어떻게 활용하는지 소개하고, 글을 읽고 저장하며 Project의 진행 과정을 따라갈 수 있는 경험을 만듭니다. Labs 연결은 MVP 이후에 추가합니다.

독자에게 쓸모 있는 AX 경험과 실제 결과물을 전달하는 채널로 운영합니다. 콘텐츠와 사용 경험을 통해 AX Notes의 신뢰와 정체성을 쌓고, 그 성과가 파운더이자 운영자 개인에 대한 신뢰로도 이어지도록 합니다. 장기적으로는 광고를 붙여 지속 가능한 수익도 실험합니다.

## 프로젝트 목표

- 글을 읽기 쉽고, 알림, 저장, 공유가 쉽다.
- 앱을 만드는 과정 자체를 AX Notes의 Project로 기록한다.
- 의미있는 결과물을 배포하는 채널로 사용하고 이후 광고 수익화를 검토한다.

## MVP 첫 번째 생존자

살아남기 위한 최소한의 기능

- Notes 목록과 글 읽기
- 온디바이스 개인화
  - 북마크
  - 나중에 읽기 알람
  - 메모, 글에 연결된 사용자 메모를 다른 타입의 북마크로 포함
  - 검색, 메모 함께 검색

MVP 이후에는 Labs 소개와 실행 진입점을 추가합니다.

## 만드는 과정을 글로 남기기

앱 개발은 AX Notes의 독립적인 **Project**로 다룹니다. 이 저장소에는 앱 코드와 설계 자료를 두고, 독자에게 공개할 글은 AX Notes Public의 Note로 작성해 해당 Project에 연결합니다.

예상 기록 흐름:

1. 왜 AX Notes에 앱이 필요한가 — 독자의 경험, AX Notes의 역할, 기대하는 변화
2. 무엇부터 만들 것인가 — 참여 흐름과 첫 버전의 범위
3. 어떤 방식으로 만들 것인가 — 플랫폼과 기술 선택의 이유
4. AI와 함께 만들기 — 실제 작업, 시행착오, 수정한 결정
5. 직접 써보고 고치기 — 사용 경험과 독자의 반응
6. 배포와 수익화 실험 — 운영 결과와 다음 과제

각 글에는 실제로 진행한 일, 선택의 이유, 확인한 결과, 남은 질문을 기록합니다. 구현하지 않은 기능이나 검증하지 않은 성과를 완료한 것처럼 소개하지 않습니다.

## 현재 상태

**0.3.0 피드백·편집 디자인 후보.** Android 앱, 정적 JSON 연동, 로컬 저장·검색·알림과 테스트가 구현되었습니다. [이번 후보의 변경·설치 주의·최종 검증 범위](docs/RELEASE_0.3.0.md)를 먼저 확인하세요. [0.2.0 기록](docs/RELEASE_0.2.0.md)과 [과거 기기 검증 보고서](docs/TEST_REPORT.md)는 이전 버전의 증거이며, 이번 후보의 실기기 검증을 대신하지 않습니다.

확정한 MVP 방향:

- 앱 형태와 지원 플랫폼: Android 전용 모바일 앱, Android 8.0 이상
- 콘텐츠: Public 웹 빌드의 정적 JSON으로 가져옴. 필요한 웹 저장소 변경도 함께 진행
- 메모: 글 연결 메모만 제공
- 저장과 계정: 기기 내부 저장, 계정 없음, 백업 없음
- 알림: 스케줄러 수준의 나중에 읽기 알림, 지연 허용
- 초기 배포: 내부 APK

세부 기술과 콘텐츠 계약은 TRD 초안을 기준으로 확정합니다.

## Android 개발

- `app/`: 새로 추가한 Android 앱 모듈 (Kotlin, Compose, Room, WorkManager)
- 최소 API 26, compile/target API 35, JDK 17 이상
- Android SDK 설치 후 `local.properties`에 SDK 경로를 설정하거나 ANDROID_HOME을 지정합니다
- `./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest`
- 내부 APK: `app/build/outputs/apk/debug/app-debug.apk`
- 내부 테스트 applicationId: `net.msalt.axnotes.internal`
- 내부 빌드도 실제 웹 JSON 피드가 기본입니다. 0.2.0에서 이전 샘플 설정을 한 번 실제 피드로 전환하며 개인 기록과 콘텐츠 캐시는 지우지 않습니다. 0.3.0 화면에서는 샘플 선택을 제공하지 않으며, 디버그 테스트 코드에서만 별도 fixture를 사용할 수 있습니다.
- 창 너비에 따라 하단 탐색·탐색 레일·목록/본문 분할 화면을 사용합니다. [태블릿 설계](docs/ADAPTIVE_DESIGN.md)를 확인하세요.
- 앱을 삭제하거나 데이터를 초기화하면 개인 기록을 복구할 수 없습니다
- SDK·Gradle 캐시, 빌드 산출물과 서명 키를 저장소에 넣지 않습니다
