# AX Notes 0.2.0 내부 테스트

검증일: 2026-10-08. 내부 테스트 APK이며 정식 출시판이 아닙니다.

## 변경 사항

- 실제 공개 웹 피드가 기본입니다. 이전 내부 빌드의 샘플 설정은 한 번 실제 피드로 전환합니다.
- 피드 변경 또는 접속 실패가 기존 콘텐츠 캐시·북마크·메모·알림을 삭제하지 않습니다. 이전 샘플 캐시를 표시하는 경우 실제 출처와 연결 변경 대기 상태를 구분합니다.
- 600dp부터 탐색 레일, 840dp부터 목록/상세 분할 화면을 사용합니다. 큰 글자는 1000dp부터 분할하며 높이가 부족하면 단일 화면으로 표시합니다.
- 읽기 폭, 편집 화면 스크롤, 큰 글자, 회전/창 크기 변경, 메모를 작성하다 이동하는 흐름을 보강했습니다. 상세 기준은 [태블릿 설계](ADAPTIVE_DESIGN.md)를 참고하세요.

## 이번 APK의 기기 검증 제한

클라우드에 하드웨어 가속(KVM)이 없어 공식 Android Emulator 37.2.12의 소프트웨어 CPU 모드를 사용했습니다.

- API 26 / Google APIs x86: boot 완료 플래그는 확인했지만 실제 화면에는 `Android is starting…`이 남았습니다. 첫 스트리밍 설치는 240초 안에 완료되지 않았습니다. 마지막으로 새 AVD, CPU 1개, Vulkan 비활성화, 낮은 RAM 요청(에뮬레이터가 1536MB로 올림)으로 직렬 실행한 비스트리밍 설치도 300초 후 시간 초과되었습니다. 이후 패키지 조회에서도 앱 설치가 확인되지 않았습니다. 앱 기능 실패로 해석하지 않습니다.
- API 36 / Google APIs x86_64 / 1280×800, 160dpi: Android 부팅 완료 전 호스트 응답도 느려졌으며, 에뮬레이터 종료 기록은 `-9`였습니다. 종료 원인을 앱 문제나 메모리 부족으로 단정하지 않습니다. 앱 설치·실행 단계에 도달하지 못했습니다.
- 따라서 이번 APK의 실제 기기에서 피드 받기, WebView 이미지 렌더링, 네트워크를 차단한 뒤 캐시 재열기, 앱 프로세스 재시작, 회전/큰 글자 화면 검증은 **아직 통과한 항목이 아닙니다**. 위의 69개 JVM/Robolectric 결과와 별개입니다.
- 이전 0.1.0의 에뮬레이터 결과는 다른 APK·샘플 모드의 결과이므로 이번 버전 검증으로 계산하지 않았습니다.
