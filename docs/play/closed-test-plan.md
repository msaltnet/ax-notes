# AX Notes 비공개 테스트

패키지: `net.msalt.axnotes`. 대상 빌드: 0.3.0 / versionCode 3 / API 36.
테스터: 모집 예정. 문의: msalt.net.help@gmail.com.

## 참여 요건

Play Console에 표시된 신규 개인 계정 요건은 12명 이상이 연속 14일 비공개 테스트에 참여하는 것입니다.
릴리스 초안 생성이나 이메일 목록 등록만으로 기간이 시작되지는 않습니다.
테스터가 실제 참여 링크에서 참여를 선택하고 테스트를 수행해야 합니다.
중도 이탈에 대비하여 15명 이상 모집을 권장하되, 참여나 피드백을 허위로 기록하지 않습니다.
요건을 충족한 뒤 테스트 내용·피드백·수정 내역을 바탕으로 프로덕션 액세스를 신청합니다.

## 확인할 흐름

1. Play에서 설치하고 실제 피드가 표시되는지 확인합니다.
2. 글을 열고 스크롤한 뒤 메모를 작성·저장·취소하고 읽던 위치가 유지되는지 확인합니다.
3. 북마크와 메모를 검색하고 앱을 재실행해 기록이 유지되는지 확인합니다.
4. 알림 권한 허용/거부와 읽기 알림을 확인합니다. 배터리 관리로 지연될 수 있습니다.
5. 내려받은 본문을 오프라인으로 읽고 외부 링크·공유를 확인합니다.
6. 밝은/어두운 테마, 글자 크기 확대, 화면 회전과 가능한 태블릿/폴더블에서 확인합니다.
7. Android 16에서 시스템 바·키보드·뒤로가기와 접근성을 확인합니다.

오류 제보에는 기기명, Android 버전, 재현 순서, 기대/실제 결과를 요청합니다.
메모 등 개인정보가 포함된 스크린샷은 가려서 보내도록 안내합니다.

## 등록 자료와 남은 작업

- 한국어/영어 등록 문안: `store-info.txt`
- 서명 AAB: `app/build/outputs/bundle/release/app-release.aab`
- 공개 개인정보처리방침 URL과 앱 내부 접근 경로 필요
- 스토어 아이콘(512×512), 그래픽 이미지(1024×500), 실제 앱 스크린샷 필요
- Play Console 콘텐츠 등급 설문·타겟층·데이터 보안·카테고리·배포 국가·무료 가격 설정 필요
- 비공개 트랙에 테스터 이메일 목록 또는 Google 그룹을 연결한 뒤 참여 링크 제공
- Play 검토 및 테스트 공개 후 실제 12명/14일 충족 여부 확인

참고: https://support.google.com/googleplay/android-developer/answer/14151465
