# AX Notes Preview — 2026-10-20

This is a debug-signed test APK, not a production or Google Play release.

- Based on main `da16a7acb61d30e9bdc539da59bb8338f795ba14`, including PR #25's icon-only navigation selection and circular interaction feedback.
- Preview package: `net.msalt.axnotes.preview20261020`; launcher name: **AX Notes Preview**.
- Version: `0.3.0-preview.20261020` (code 3), Android 8.0/API 26 or newer.
- Installs alongside the original `net.msalt.axnotes.internal` app without replacing it. Existing notes, bookmarks and reminders stay in the original app; no automatic data migration is provided. Do not uninstall the original app or clear its data.
- Uses the live AX Notes feed at https://ax.msalt.net/app/v1/manifest.json.
- Built with a fresh GitHub Actions debug signing key. Future builds may have a different signing certificate and are not guaranteed to update this preview in place. This is not a persistent production signing setup.
- Build checks: complete debug unit/Robolectric suite, lint, debug APK, instrumentation-test APK compilation, release Kotlin compilation, Python script tests and design token verification. Physical-device execution and instrumentation execution are not covered by these checks.
- The navigation pixel tests use native Canvas rendering under Robolectric, preserving the original icon/background pixel assertions and adding a deliberately corrupted background negative control. This avoids the original asynchronous Window-capture timeout; it does not replace physical-device visual review.
- Figma library installation/synchronization is not part of this release.

Normal builds retain their original application IDs and launcher name. The preview identity is enabled only by `-PaxPreview=true` for the debug build.

The release includes an APK, SHA256SUMS, and BUILD-INFO.txt with the exact source commit, workflow commit, run URL and signing certificate details. No production deployment, account credential provisioning or device data changes are performed.
